# Complete Portfolio + Admin Panel

This is a complete working starter implementation based on the supplied Figma screenshot:
dark/purple visual system, hero, about, skills, featured projects, timeline, contact form and responsive layout.

## Included
- React + TypeScript + Vite
- Tailwind CSS v4
- Framer Motion animations
- Lucide icons
- Responsive public portfolio
- Admin login
- Admin dashboard
- Project CRUD using localStorage
- Skills management
- Experience management
- Contact messages management
- Mobile responsive layout

## Run

```bash
npm install
npm run dev
```

## Important

This starter uses `localStorage`, so it works immediately without a backend.
For production, replace the storage service with your API/database and secure authentication.
